SHAREEF SONS BUSINESS MANAGER — ANDROID APK SETUP

This project is prepared for Capacitor Android packaging.

IMPORTANT — WHITE SCREEN FIX:
The Android APK is built by GitHub Actions, so Vercel's environment variables are NOT automatically available to the APK build.
Before running the Android workflow, add these two GitHub repository secrets:

1. VITE_SUPABASE_URL = your Supabase Project URL
2. VITE_SUPABASE_KEY = your Supabase publishable/anon key used by the web app

Do NOT put the Supabase secret/service-role key in the React app or in GitHub source files.

The workflow now stops with a clear error if either required build variable is missing.

BUILD STEPS USED BY GITHUB ACTIONS:
1. npm install
2. Check VITE_SUPABASE_URL and VITE_SUPABASE_KEY
3. npm run build
4. npx cap add android
5. npx capacitor-assets generate --android
6. npx cap sync android
7. ./gradlew assembleDebug
8. Upload APK artifact
