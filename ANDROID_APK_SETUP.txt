SHAREEF SONS BUSINESS MANAGER — ANDROID APK SETUP

This package prepares the existing React + Vite project for Capacitor Android packaging.

IMPORTANT:
- Existing React/Supabase source files were kept.
- Capacitor configuration was added.
- Android native project is NOT included yet because it must be generated after npm install.

NEXT STEPS:
1. Upload/replace these project files in GitHub.
2. In a Node-capable environment run:
   npm install
   npm run build
   npx cap add android
   npx cap sync android
3. Then build the Android APK/AAB using Android Studio or a cloud Android build service.
